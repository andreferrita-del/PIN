# PIN

**A Compiler Made in C++**

PIN is a programming language inspired by JSON, Python and Lua.

## Current version

PIN Core 0.1 - Lexer foundation.

## Build

```bash
./build.sh
```

## Token inspection

```bash
pin.exe tokens examples/hello.pin
```

## Language direction

- JSON-inspired objects and arrays
- Python-inspired readability
- Lua-inspired lightweight scripting
- C++ implementation
- Windows x64 target
